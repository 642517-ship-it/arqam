# أرقام — لعبة المطابقة

لعبة ويب (PWA) تُثبَّت على الهاتف وتعمل دون إنترنت.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا باسم `arqam` (عام / Public).
2. ارفع كل ملفات هذا المجلد إلى جذر المستودع:
   `index.html` · `manifest.webmanifest` · `sw.js` · `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` · `apple-touch-icon.png`
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `root` ← Save.
4. انتظر دقيقة، ثم افتح: `https://<اسم-المستخدم>.github.io/arqam/`

## التثبيت على الهاتف

- **أندرويد (Chrome):** افتح الرابط ← قائمة النقاط الثلاث ← "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية".

## عند تحديث اللعبة

بعد رفع نسخة جديدة من `index.html`، غيّر رقم النسخة في السطر الأول من `sw.js`
(مثلًا `arqam-v1` ← `arqam-v2`) وإلا بقيت النسخة القديمة محفوظة في ذاكرة الهاتف.

## ملاحظات

- النقاط وأفضل النتائج واللعبة المحفوظة تُخزَّن في `localStorage` على الجهاز نفسه، لكل مستوى على حدة.
- الخط Cairo يُحمَّل من الإنترنت؛ عند انقطاعه تعمل اللعبة بخط النظام دون مشكلة.
